# Spicetify Side Hide

Spicetify Side Hide is a simple Spicetify extension that hides the Spotify sidebar and associated buttons. 

## How it works
- On startup, injects CSS that hides every right-sidebar toggle button (Listening Activity, What's New, Now Playing, Queue, Connect) and collapses the right-hand sidebar entirely.
- The playbar's now-playing widget (album art + track, bottom-left) stays visible.

## Note: Consider Sidebar Customizer
For more flexibility and control, check out the **[Sidebar Customizer](../sidebar-customizer/README.md)** extension. It offers:
- Individual toggle controls for each sidebar element (Listening Activity, What's New, Queue, Connect, Now Playing View)
- Preference persistence via localStorage
- Easy-to-use toggles in the profile menu
- Cleaner appearance with proper styling
